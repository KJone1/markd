# markd

A minimalist local editor built because existing markdown tools fail to cleanly handle markdown made for LLMs like skills.

## Features

- **Full WYSIWYG Markdown**: Direct visual editing without raw source toggle friction.
- **Skills & Anthropic XML Tags**: Native support for SKILLS frontmatter and tag-based section splitting instead of treating XML as ignored comments.
- **HTML Out of the Box**: Renders HTML directly alongside markdown.
- **Quick File Inspection**: Opens non-markdown files instantly for inspection without strict file-type restrictions.
